# Nexus

Nexus is a Laravel package for rapidly building an admin panel: content types ("modules") are described with PHP 8 attributes directly on the Eloquent model, and the package automatically generates forms, tables, validation, and API resources.

## Modules

Additional and ready-to-use modules for the package can be found on the official project website:
👉 [https://www.nexus-cms.shop/](https://www.nexus-cms.shop/)
