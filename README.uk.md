# Nexus

Nexus — це Laravel-пакет для швидкої побудови адмін-панелі: типи контенту («модулі») описуються PHP 8 атрибутами безпосередньо на Eloquent-моделі, а пакет автоматично формує форму, таблицю списку, валідацію та API-ресурси.

## Модулі

Готові та додаткові модулі до пакету можна знайти на офіційному сайті проєкту:
👉 [https://www.nexus-cms.shop/](https://www.nexus-cms.shop/)

## Ліцензія

Пакет є open-core і розповсюджується під ліцензією MIT — дивіться файл LICENSE для деталей.

Шар GraphQL API та модуль Page/візуального блочного редактора (вбудовані типи блоків Hero/Text/Image/CTA) є преміум-доповненнями, які розповсюджуються окремо як вміст `app/Nexus/Plugins`/`app/Nexus/Modules` для кінцевого застосунку — вони не входять до цього репозиторію. Ці та інші модулі доступні на [https://www.nexus-cms.shop/](https://www.nexus-cms.shop/).
